# Changelog

## 1.0.0 — initial local release candidate

- Establish GunyahVM from the Xiaomi Pad 8 Pro mainline virtualization implementation, retaining relevant history and upstream attribution.
- Combine Linux and Windows tools, crosvm, UEFI, drivers and host integration in one `gunyahvm` ARM64 package.
- Add live firmware discovery, memory-derived defaults, `check`, `about`, active-seat permissions and a finite-limit privilege-dropping launcher.
- Provide matching English/Chinese documentation, DCO contribution guidance, offline tests and non-publishing CI packaging.
