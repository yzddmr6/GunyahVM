# Windows 来宾

使用自己的 Windows 11 ARM64 ISO 创建虚拟机，离线完成安装和本地账户设置，再在 GunyahVM 窗口查看登录界面、通过密钥 SSH 控制来宾。

Windows 来宾可在系统 1.1.1 及以上的小米平板 8 Pro 上运行。

## 准备镜像与资源

准备有效的 Windows 11 ARM64 ISO 和适用的许可证。GunyahVM 不提供 Windows 镜像或激活服务。选择 ISO 中存在的版本；默认选择 Pro，创建时可在**高级**中填写版本名或镜像索引。

Windows 至少需要 4608 MiB 来宾内存和 64 GiB 虚拟磁盘，默认使用 4 个虚拟 CPU。宿主还须为系统和显示保留足够内存。虚拟磁盘按需增长，部署时须有足够的实际可用存储空间。

## 通过应用安装

1. 点击 **+**，选择 **Windows 11**，再选择 ISO 文件。
2. 填写离线本地用户名和密码，并再次确认密码。这是 Windows 登录账户，不是用于控制虚拟机的服务账户。
3. 确认内存、CPU 和磁盘大小，点击**创建**。准备安装介质期间保持应用运行。
4. 选中虚拟机并点击**启动**。部署程序应用镜像、安装驱动，然后自动移除安装介质并启动 Windows。
5. 点击**打开显示**，在应用内完成地区、键盘、许可和隐私选项，进入本地账户登录界面。

首次配置从安装介质中的固定离线包安装 OpenSSH，不通过 Windows Update 下载功能。本地账户路径不要求 Microsoft 账户，也不要求互联网连接。

## 通过命令行安装

```sh
gunyahvm create windows --os windows11 --iso /path/to/windows-arm64.iso --local-user vmuser
gunyahvm start windows
gunyahvm view windows
```

创建命令在终端隐藏输入本地账户密码；自动化可通过 `--password-fd` 传入，不要把密码放在命令行参数中。`--edition` 选择版本名或索引。应用和 CLI 共用虚拟机配置。

## GPU 加速

设备支持时，新建的 Windows 虚拟机默认使用 GPU 加速：Windows 桌面和 Direct3D 11 程序用平板的 Adreno GPU 绘制。来宾驱动是 anonymix007 和 Droid-VM 团队的 WDDM 显示驱动，由 Gl1ch5 打包（build-43），其中的 Turnip 重新编译以识别 Adreno 830。设备管理器里它的名字是“Qualcomm Adreno 829 (DroidVM, unofficial build)”。

安装介质会预置驱动。Windows 设置（安装、第一次启动和第一次登录）在基本显示下进行，因为设置页面在这个驱动下画不出来。第一次登录完成后，虚拟机页面会提示下次启动起使用 GPU 加速，此后每次启动都用 GPU。

在**设置 → 显示 → 图形**中选**基本显示**改用处理器绘制（例如 Windows 更新后又出现设置页面时），选 **GPU 加速**改回来。虚拟机用 GPU 加速启动过以后，它的基本显示也与宿主共享内存。旧版 GunyahVM 建的 Windows 虚拟机没有 GPU 驱动：启动它，等就绪后在它的菜单中选**安装 GPU 驱动**（或运行 `gunyahvm install-gpu-driver 名称`），再重启。驱动通过虚拟机的控制账户复制并安装。

GPU 加速需要能共享虚拟机内存的系统内核，以及 Adreno 渲染节点和 `/dev/udmabuf` 的访问权限。缺少时，新建的虚拟机使用基本显示，**设置**里会说明缺什么。

## 控制与关机

GunyahVM 创建独立的控制账户，使用每台虚拟机专属的 SSH 密钥，并仅允许宿主网关访问控制端口。该账户不出现在 Windows 登录界面；隐藏登录入口不会禁用 SSH 或网络登录。本地交互账户保留在登录界面。

应用显示运行状态和来宾 IP。正常关机使用 SSH 通道，等待 Windows 退出后再清理网络。在应用中点击**关机**，或运行：

```sh
gunyahvm stop windows
```

保持来宾虚拟网卡和控制服务可用。强制停止相当于断电，可能损坏来宾数据。

## 网络与显示限制

- 安装可以完全离线；默认虚拟网络仍使用宿主共享 NAT，并不是外网隔离。若要保持来宾断网，在宿主限制该虚拟网络的外部转发，同时保留宿主到来宾的 SSH 控制。关闭整个虚拟网络也会使正常关机失去 SSH 通道。
- 基本显示是软件帧缓冲。Windows 来宾不提供共享文件夹。
- 使用 GPU 加速时，虚拟机的内存与宿主共享，不受内存保护；GPU 的命令和数据传输需要这样。鼠标和触控板移动指针，各个按键和滚动都可用，手指直接触控屏幕；基本显示的触控输入方式不适用。应用本身重启后，无法把正在运行的虚拟机的画面接回来，请用远程桌面或重启虚拟机。
- 不提供来宾 Secure Boot 和 vTPM。来宾驱动（包括 GPU 驱动）是测试签名的，Windows 运行在测试模式，桌面上显示“测试模式”字样。
- 更新宿主软件包不会修改已经部署的 Windows 磁盘或旧安装介质。要使用新的首次配置逻辑，须重新创建安装介质和虚拟机。

## 处理部署错误

保持错误现场，查看来宾 `C:\gunyahvm\first-boot.log` 和 `openssh-install*.log`。宿主虚拟机目录中的 `deployment-logs` 保存 DISM 和离线驱动日志。先解决日志报告的最早错误，再重新部署；不要用强制关机掩盖安装失败。

电量和被动降频不影响启动或运行。受监测热区达到内核公布的 hot 温控点（没有 hot 时取 critical）时，应用拒绝启动或请求来宾正常关机。
