# Windows 来宾

使用自己的 Windows 11 ARM64 ISO 创建虚拟机，离线完成安装和本地账户设置，再通过本机 VNC 查看登录界面、通过密钥 SSH 控制来宾。

Windows 来宾仅支持一加平板 2 Pro，须使用带 Gunyah 虚拟机接口的 7.4 内核；对应系统版本尚未发布。小米平板 8 Pro 的支持范围为 Linux 来宾。

## 准备镜像与资源

准备有效的 Windows 11 ARM64 ISO 和适用的许可证。GunyahVM 不提供 Windows 镜像或激活服务。选择 ISO 中存在的版本；默认选择 Pro，可填写版本名或镜像索引。

Windows 至少需要 4608 MiB 来宾内存和 64 GiB 虚拟磁盘，默认使用 2 个虚拟 CPU。宿主还须为系统和显示保留足够内存。虚拟磁盘按需增长，部署时须有足够的实际可用存储空间。

## 通过应用安装

1. 点击 **+**，选择 **Windows 11 ARM64 ISO**，填写镜像路径。
2. 填写离线本地用户名和密码。这是 Windows 登录账户，不是用于控制虚拟机的服务账户。
3. 确认内存、CPU 和磁盘大小，点击**创建**。准备安装介质期间保持应用运行。
4. 选中虚拟机并点击**启动**。部署程序应用镜像、安装驱动，然后自动移除安装介质并启动 Windows。
5. 点击**显示**，在 VNC 窗口内完成地区、键盘、许可和隐私选项，进入本地账户登录界面。

首次配置从安装介质中的固定离线包安装 OpenSSH，不通过 Windows Update 下载功能。本地账户路径不要求 Microsoft 账户，也不要求互联网连接。

VNC 只监听宿主回环地址，但不验证连接者身份；同一宿主的其他账户也可控制来宾。不要在有不可信本地用户的宿主上启用它。详细权限见[安全模型](security.zh-CN.md)。

## 通过命令行安装

```sh
gunyahvm create windows --os windows11 --iso /path/to/windows-arm64.iso --local-user vmuser
gunyahvm start windows
gunyahvm view windows
```

创建命令在终端隐藏输入本地账户密码；自动化可通过 `--password-fd` 传入，不要把密码放在命令行参数中。`--edition` 选择版本名或索引。应用和 CLI 共用虚拟机配置。

## 控制与关机

GunyahVM 创建独立的控制账户，使用每台虚拟机专属的 SSH 密钥，并仅允许宿主网关访问控制端口。该账户不出现在 Windows 登录界面；隐藏登录入口不会禁用 SSH 或网络登录。本地交互账户保留在登录界面。

应用显示运行状态和来宾 IP。正常关机使用 SSH 通道，等待 Windows 退出后再清理网络。在应用中点击**关机**，或运行：

```sh
gunyahvm stop windows
```

保持来宾虚拟网卡和控制服务可用。强制停止相当于断电，可能损坏来宾数据。

## 网络与显示限制

- 安装可以完全离线；默认虚拟网络仍使用宿主共享 NAT，并不是外网隔离。若要保持来宾断网，在宿主限制该虚拟网络的外部转发，同时保留宿主到来宾的 SSH 控制。关闭整个虚拟网络也会使正常关机失去 SSH 通道。
- Windows 使用软件帧缓冲和本机 VNC，不提供 virgl、其他来宾 3D 加速或共享文件夹。
- 不提供来宾 Secure Boot 和 vTPM。来宾驱动使用随附的测试签名配置。
- 更新宿主软件包不会修改已经部署的 Windows 磁盘或旧安装介质。要使用新的首次配置逻辑，须重新创建安装介质和虚拟机。

## 处理部署错误

保持错误现场，查看来宾 `C:\gunyahvm\first-boot.log` 和 `openssh-install*.log`。宿主虚拟机目录中的 `deployment-logs` 保存 DISM 和离线驱动日志。先解决日志报告的最早错误，再重新部署；不要用强制关机掩盖安装失败。

温度保护读取运行内核 sysfs 中所有定义了 passive 温控点的热区。任一热区达到其 passive 温度时拒绝启动，并提示设备正在降频；运行中达到该热区的 hot 温度时请求正常关机，没有 hot 时使用 critical 温度减 5°C。超过既有关机期限仍未退出时才强制停止。提示和状态记录包含触发热区、温度及温控点；电量保护保持不变。
